### Fix Record - 2025-01-28 (TypeScript编译错误修复)

-   **Problem Description:** 运行 `npm run server:dev` 时出现 TypeScript 编译错误，`CompatibleResponse` 接口无法正确扩展 `VercelResponse`，错误信息：`Property 'statusCode' is optional in type 'CompatibleResponse' but required in type 'ServerResponse<IncomingMessage>'`。
-   **Root Cause (Optional):** `CompatibleResponse` 接口使用 `extends` 继承 `VercelResponse`，但 TypeScript 类型系统认为它需要兼容 `ServerResponse<IncomingMessage>`，而 `statusCode` 属性在 `CompatibleResponse` 中是可选的，但在 `ServerResponse` 中是必需的，导致类型不兼容。
-   **Solution:** 将接口扩展改为类型交叉（type intersection），使用 `type CompatibleResponse = VercelResponse & { ... }` 的方式定义，并将 `statusCode`、`setHeader`、`end` 等属性标记为可选，避免与 `ServerResponse` 的必需属性冲突。
-   **Impact Scope:**
    -   `server/utils/response-vercel.ts` - 修复类型定义
