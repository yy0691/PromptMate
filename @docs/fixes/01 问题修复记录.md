### Fix Record - 2025-01-28

-   **Problem Description:** 谷歌和GitHub登录功能未实现，前端调用后端API时出现 `ERR_CONNECTION_REFUSED` 错误。OAuth回调处理不完整，Electron环境下缺少自定义协议处理。
-   **Root Cause (Optional):** 
    1. 后端服务器可能未启动，导致 `ERR_CONNECTION_REFUSED` 错误
    2. Electron主进程中未注册自定义协议 `promptmate://` 来处理OAuth回调
    3. 前端缺少OAuth回调处理逻辑，无法完成OAuth登录流程
    4. preload脚本中缺少OAuth回调的IPC通信接口
-   **Solution:** 
    1. **Electron主进程OAuth处理** (`src/main/main.cjs`):
       - 在应用启动前注册自定义协议 `promptmate://`
       - 添加 `open-url` 事件处理（macOS）和 `second-instance` 事件处理（Windows/Linux）来捕获OAuth回调
       - 实现 `handleOAuthCallback` 函数解析OAuth回调URL并提取code、error、state参数
       - 通过IPC将OAuth回调数据发送到渲染进程
       - 添加 `open-external` IPC处理，用于在外部浏览器中打开OAuth授权页面
    2. **Preload脚本增强** (`src/main/preload.cjs`):
       - 添加 `onOAuthCallback` 方法，允许渲染进程监听OAuth回调事件
       - 添加 `openExternal` 方法，用于打开外部链接
    3. **认证Hook增强** (`src/hooks/useAuth.tsx`):
       - 在 `AuthContextType` 接口中添加 `handleOAuthCallback` 方法
       - 实现 `handleOAuthCallback` 函数，调用 `authService.oauthCallback` 完成OAuth登录流程
       - 自动保存token和用户信息
    4. **AuthDialog组件完善** (`src/components/AuthDialog.tsx`):
       - 完善 `handleOAuthLogin` 函数，区分Electron和浏览器环境
       - Electron环境：使用 `electronAPI.openExternal` 打开外部浏览器，通过IPC监听回调
       - 浏览器环境：打开弹出窗口，通过URL参数处理回调
       - 添加 `handleOAuthCallback` 和 `handleOAuthLoginCallback` 函数处理OAuth回调
       - 添加 `checkBrowserOAuthCallback` 函数检查浏览器环境的URL参数
       - 在组件挂载时自动检查URL参数（浏览器环境）
-   **Impact Scope:**
    -   `src/main/main.cjs` - Electron主进程OAuth处理
    -   `src/main/preload.cjs` - Preload脚本IPC接口
    -   `src/hooks/useAuth.tsx` - 认证Hook OAuth支持
    -   `src/components/AuthDialog.tsx` - OAuth登录对话框完善

**注意：** 要使用OAuth登录功能，需要：
1. 确保后端服务器正在运行（默认端口8787）
2. 在Supabase中配置Google和GitHub OAuth提供商
3. 在Supabase中配置正确的重定向URI：
   - Electron环境：`promptmate://oauth`
   - 浏览器环境：`http://localhost:5173/auth/callback`（开发）或实际域名（生产）
