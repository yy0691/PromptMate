# 提示词分类问题调试指南

## 问题现象

用户反馈：编辑提示词时，修改分类后，该提示词会自动变为"未分类"，且再次修改分类也无法成功修改掉。

## 调试步骤

### 1. 打开浏览器开发者工具

1. 按 `F12` 或右键点击页面 → 选择"检查"
2. 切换到 "Console"（控制台）标签页
3. 清空控制台日志（点击🚫图标）

### 2. 重现问题并观察日志

#### 步骤 A：选择一个提示词并编辑

1. 在提示词列表中选择一个提示词
2. 点击"编辑"按钮
3. **观察控制台日志**，应该看到：

```
🔄 resetForm 调用: {
  promptId: "xxx",
  promptCategory: "原分类ID",
  calculatedCategory: "计算后的分类ID",
  availableCategories: [...]
}
```

**检查点**：
- `promptCategory` 是什么值？（空字符串？undefined？还是有效的分类ID？）
- `calculatedCategory` 是什么值？
- `availableCategories` 列表中有哪些分类？

#### 步骤 B：修改分类

1. 在分类下拉框中选择一个新的分类
2. **观察控制台日志**，应该看到：

```
🔄 分类选择变化: {
  oldCategory: "旧分类ID",
  newCategory: "新分类ID"
}

📝 updateField - category 变化: {
  oldValue: "旧分类ID",
  newValue: "新分类ID",
  promptCategory: "原提示词的分类ID",
  hasChanges: true
}
```

**检查点**：
- `newCategory` 是否是你选择的分类ID？
- `hasChanges` 是否为 `true`？

#### 步骤 C：保存更改

1. 点击"保存"按钮或等待自动保存
2. **观察控制台日志**，应该看到：

```
💾 保存提示词: {
  promptId: "xxx",
  oldCategory: "原分类ID",
  newCategory: "新分类ID",
  stateCategory: "state中的分类ID",
  availableCategories: [...]
}

🔄 更新 selectedPrompt: {
  id: "xxx",
  oldCategory: "原分类ID",
  newCategory: "新分类ID",
  updatedSelected: { ... }
}
```

**检查点**：
- `newCategory` 是否正确？
- `updatedSelected` 对象中的 `category` 字段是什么值？

#### 步骤 D：再次打开编辑

1. 关闭编辑对话框
2. 再次打开同一个提示词的编辑
3. **观察控制台日志**和分类下拉框显示

**检查点**：
- 控制台中 `resetForm` 的 `promptCategory` 是什么值？
- 分类下拉框显示的是什么？

### 3. 常见问题诊断

#### 问题 1：`promptCategory` 为空或 undefined

**现象**：
```
🔄 resetForm 调用: {
  promptCategory: "",  // 或 undefined
  calculatedCategory: "general"  // 回退到默认分类
}
```

**原因**：提示词对象的 `category` 字段本身就是空的

**解决方案**：检查 `updatePrompt` 函数是否正确更新了 `category` 字段

#### 问题 2：分类ID与分类名称混淆

**现象**：
```
🔄 分类选择变化: {
  newCategory: "开发编程"  // 应该是ID，不是名称
}
```

**原因**：Select 组件的 `value` 使用了分类名称而不是ID

**解决方案**：确保 `SelectItem` 的 `value` 属性使用 `cat.id` 而不是 `cat.name`

#### 问题 3：保存后 `selectedPrompt` 未更新

**现象**：
- 保存日志显示正确
- 但没有看到 "🔄 更新 selectedPrompt" 日志

**原因**：`updatePrompt` 函数中的 `selectedPrompt` 更新逻辑未执行

**解决方案**：检查 `usePrompts.tsx` 中的 `updatePrompt` 函数

#### 问题 4：`useEffect` 未触发同步

**现象**：
- 保存成功
- `selectedPrompt` 已更新
- 但编辑表单中的分类仍然显示旧值

**原因**：`usePromptEditor.ts` 中的 `useEffect` 依赖数组不完整

**解决方案**：确保 `useEffect` 监听了 `prompt.category` 的变化

### 4. 数据验证

#### 检查 localStorage 中的数据

在控制台中运行：

```javascript
// 查看所有提示词
const prompts = JSON.parse(localStorage.getItem('prompts') || '[]');
console.table(prompts.map(p => ({ id: p.id, title: p.title, category: p.category })));

// 查看所有分类
const categories = JSON.parse(localStorage.getItem('categories') || '[]');
console.table(categories);
```

**检查点**：
- 提示词的 `category` 字段是分类ID还是分类名称？
- 分类列表中是否包含该分类ID？

#### 检查 SQLite 数据库（如果启用）

在控制台中运行：

```javascript
// 获取数据库客户端
const { databaseClient } = await import('./lib/databaseClient');

// 查看所有提示词
const prompts = await databaseClient.getAllPrompts();
console.table(prompts.map(p => ({ id: p.id, title: p.title, category: p.category })));

// 查看所有分类
const categories = await databaseClient.getAllCategories();
console.table(categories);
```

## 报告问题

如果按照上述步骤仍然无法解决问题，请提供以下信息：

1. **完整的控制台日志**（从打开编辑到再次打开编辑的全部日志）
2. **localStorage 数据快照**（上述验证命令的输出）
3. **使用的存储模式**（localStorage 还是 SQLite）
4. **浏览器信息**（Chrome/Edge/Firefox 及版本号）
5. **具体操作步骤**（哪个提示词，修改到哪个分类）

## 临时解决方案

如果问题紧急，可以尝试以下临时方案：

### 方案 1：手动修复数据

```javascript
// 1. 获取所有提示词
const prompts = JSON.parse(localStorage.getItem('prompts') || '[]');

// 2. 找到有问题的提示词
const problemPrompt = prompts.find(p => p.id === '你的提示词ID');

// 3. 手动设置分类
problemPrompt.category = '正确的分类ID';

// 4. 保存回 localStorage
localStorage.setItem('prompts', JSON.stringify(prompts));

// 5. 刷新页面
location.reload();
```

### 方案 2：清空缓存重新导入

1. 导出所有数据（设置 → 数据导入导出）
2. 清空浏览器缓存
3. 重新导入数据
