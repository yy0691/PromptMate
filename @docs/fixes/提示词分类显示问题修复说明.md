# 提示词分类显示问题修复说明

## 问题描述

用户反馈：编辑提示词时，修改为其他分类后，该提示词会自动变为未选择分类，且再次修改分类也无法成功修改掉。

## 问题分析

### 根本原因

经过代码排查，发现问题出在多个层面：

1. **`usePromptEditor.ts` 中的 `resetForm` 函数**
   - 问题：直接使用 `prompt.category`，没有处理分类为空的情况
   - 影响：如果 `prompt.category` 为空字符串或 undefined，会导致表单显示空分类

2. **`usePromptEditor.ts` 中的 `useEffect` 监听逻辑**
   - 问题：只在 `prompt.id` 变化时重置表单，但当 prompt 对象更新（如保存后）时，没有同步更新 state
   - 影响：用户修改分类并保存后，state 中的 category 没有同步更新，导致显示错误

3. **`PromptEditForm.tsx` 中的 Select 组件**
   - 问题：`value={state.category || categories[0]?.id || ""}` 这个逻辑会在 category 为空时自动使用第一个分类，但这只是显示层面的回退，实际 state 中的 category 仍然是空的
   - 影响：用户看到的分类和实际保存的分类不一致

4. **`usePrompts.tsx` 中的 `updatePrompt` 函数**
   - 问题：更新 `selectedPrompt` 时没有包含 `updatedAt` 字段，且没有调试日志
   - 影响：难以追踪分类更新是否正确传递

## 修复方案

### 1. 修复 `usePromptEditor.ts` 中的 `resetForm` 函数

**位置**：`src/hooks/usePromptEditor.ts:128-151`

**修改前**：
```typescript
const resetForm = useCallback(() => {
  if (prompt) {
    setState({
      title: prompt.title,
      content: prompt.content,
      category: prompt.category,  // ❌ 直接使用，可能为空
      tags: prompt.tags.join(", "),
      // ...
    });
  }
}, [prompt]);
```

**修改后**：
```typescript
const resetForm = useCallback(() => {
  if (prompt) {
    // ✅ 确保分类不为空，如果为空则使用默认分类
    const category = prompt.category && prompt.category.trim() 
      ? prompt.category 
      : (categories[0]?.id || "general");
    
    setState({
      title: prompt.title,
      content: prompt.content,
      category: category,  // ✅ 使用处理后的分类
      tags: prompt.tags.join(", "),
      // ...
    });
  }
}, [prompt, categories]);  // ✅ 添加 categories 依赖
```

### 2. 修复 `usePromptEditor.ts` 中的 `useEffect` 监听逻辑

**位置**：`src/hooks/usePromptEditor.ts:430-467`

**修改前**：
```typescript
useEffect(() => {
  const currentPromptId = prompt?.id || null;
  const prevPromptId = previousSelectedPromptIdRef.current;
  
  // 只有当提示词ID变化时才重置表单
  if (currentPromptId !== prevPromptId && !isAutoSavingRef.current) {
    resetForm();
    previousSelectedPromptIdRef.current = currentPromptId;
  }
}, [prompt?.id, resetForm]);
```

**修改后**：
```typescript
useEffect(() => {
  const currentPromptId = prompt?.id || null;
  const prevPromptId = previousSelectedPromptIdRef.current;
  
  // 只有当提示词ID变化时才重置表单
  if (currentPromptId !== prevPromptId && !isAutoSavingRef.current) {
    resetForm();
    previousSelectedPromptIdRef.current = currentPromptId;
  } else if (currentPromptId === prevPromptId && prompt && !isAutoSavingRef.current) {
    // ✅ 如果 prompt 对象更新了（比如保存后），同步更新 state
    // 只有当没有未保存的更改时才同步，避免覆盖用户的编辑
    setState(prev => {
      if (!prev.hasChanges) {
        // 确保分类不为空
        const category = prompt.category && prompt.category.trim() 
          ? prompt.category 
          : (categories[0]?.id || "general");
        
        return {
          ...prev,
          title: prompt.title,
          content: prompt.content,
          category: category,  // ✅ 同步更新分类
          tags: prompt.tags.join(", "),
          images: prompt.images || [],
          isFavorite: prompt.isFavorite,
        };
      }
      return prev;
    });
  }
}, [
  prompt?.id, 
  prompt?.category,  // ✅ 监听 category 变化
  prompt?.title, 
  prompt?.content, 
  prompt?.tags, 
  prompt?.images, 
  prompt?.isFavorite, 
  resetForm, 
  categories
]);
```

## 技术要点

### 1. 状态同步策略

- **初始化**：使用 `resetForm` 时，确保分类有默认值
- **更新同步**：通过 `useEffect` 监听 prompt 对象的变化，在没有未保存更改时同步更新 state
- **保存后同步**：`updatePrompt` 函数确保 `selectedPrompt` 正确更新

### 2. 默认分类优先级

```typescript
const category = prompt.category && prompt.category.trim() 
  ? prompt.category           // 1. 使用 prompt 的分类
  : (categories[0]?.id        // 2. 使用第一个可用分类
    || "general");            // 3. 使用默认分类 "general"
```

### 3. 避免循环更新

- 使用 `isAutoSavingRef` 标记自动保存状态，避免在自动保存时触发重置
- 使用 `prev.hasChanges` 检查，只在没有未保存更改时同步更新 state
