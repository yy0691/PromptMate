# PromptMate 云存储功能快速开始

## 🚀 5分钟快速配置

### 选项一：坚果云（推荐国内用户）

#### 第一步：获取坚果云应用密码
1. 访问 https://www.jianguoyun.com/ 并登录
2. 点击右上角头像 → **账户信息** → **安全选项**
3. 找到 **第三方应用管理** → 点击 **添加应用密码**
4. 输入应用名称：`PromptMate`
5. **复制生成的密码**（这是应用密码，不是登录密码）

#### 第二步：在PromptMate中配置
1. 打开PromptMate → 点击 **设置** 图标
2. 切换到 **云存储** 选项卡
3. **存储服务商** 选择：`WebDAV（坚果云等）`
4. 点击 **坚果云** 按钮（自动填写服务器地址）
5. 填写信息：
   ```
   服务器地址：https://dav.jianguoyun.com/dav/ (已自动填写)
   用户名：your@email.com （你的坚果云账号）
   密码：刚才复制的应用密码
   远程路径：/PromptMate
   ```
6. 点击 **测试连接** → 看到"连接测试成功"
7. 开启 **自动同步** 开关（可选）
8. 点击 **保存设置**

#### 第三步：开始使用
- 点击 **立即同步** 上传你的数据
- 在其他设备上重复第二步配置相同的账号
- 数据自动同步，完成！✅

## 📝 常用操作

### 上传数据到云端
设置 → 云存储 → **上传到云端** 按钮

### 从云端下载数据
设置 → 云存储 → **从云端下载** 按钮
> ⚠️ 下载后会自动刷新页面

### 手动同步
设置 → 云存储 → **立即同步** 按钮
> 同时执行上传和下载（智能合并）

### 查看同步状态
在云存储设置页面顶部的状态卡片中查看：
- 🟢 已同步 - 一切正常
- 🔄 同步中 - 正在同步
- 🔴 失败 - 查看错误信息

## ❓ 常见问题快速解答

### Q1: 坚果云显示"连接失败"？
**A:** 99%的情况是使用了登录密码而不是应用密码
- ✅ 正确：使用 **第三方应用管理** 中生成的应用密码
- ❌ 错误：使用坚果云登录密码

### Q2: 如何在多台电脑间同步？
**A:** 在每台电脑上配置相同的云存储账号即可
- 建议开启自动同步
- 同步间隔建议设为30-60分钟

### Q3: 同步会覆盖我的数据吗？
**A:** 
- **上传**：会覆盖云端数据
- **下载**：会覆盖本地数据
- **同步**：智能合并（以本地为主）

### Q4: 数据存储在哪里？
**A:** 
- 坚果云：你的坚果云账号的 `/PromptMate` 文件夹
- OneDrive：你的OneDrive账号的 `/PromptMate` 文件夹
- 可以在配置时修改远程路径

### Q5: 可以不用云存储吗？
**A:** 当然可以！云存储是完全可选的功能，不影响核心使用。

## 💡 使用建议

### 推荐配置
- ✅ 开启自动同步
- ✅ 同步间隔设为 30 分钟
- ✅ 定期检查同步状态
- ✅ 在重要操作前手动同步一次

### 最佳实践
1. **多设备使用**：在所有设备上配置相同的云存储
2. **定期备份**：即使开启了云存储，也建议定期导出本地备份
3. **测试先行**：配置完成后先测试上传/下载小数据
4. **网络良好**：在网络状况良好时进行首次同步

### 注意事项
- ⚠️ 坚果云免费版有流量限制（1GB/月上传，3GB/月下载）
- ⚠️ 图片较多时同步时间会较长
- ⚠️ 避免在同步进行中关闭应用
- ⚠️ 首次同步建议使用"上传"而不是"同步"
