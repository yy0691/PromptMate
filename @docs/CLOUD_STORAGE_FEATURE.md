## 🚀 快速开始

### 最快5分钟配置完成！

#### 步骤1️⃣：选择云存储服务
打开 **设置** → **云存储** 选项卡

#### 步骤2️⃣：配置坚果云（最简单）
```
1. 获取坚果云应用密码（help.jianguoyun.com/?p=2064）
2. 选择 "WebDAV（坚果云等）"
3. 填写账号和应用密码
4. 点击"测试连接"
5. 保存设置 ✅
```

#### 步骤3️⃣：开始使用
```
- 立即同步：上传+下载数据
- 上传到云端：仅上传本地数据
- 从云端下载：仅下载云端数据
```

📖 **详细教程**：查看 `云存储功能快速开始.md`

## 🔐 安全性

### 数据安全保障
- ✅ **本地存储配置** - 所有配置信息存储在本地，不上传到任何服务器
- ✅ **HTTPS加密传输** - 使用SSL/TLS加密传输数据
- ✅ **应用密码支持** - 坚果云使用应用密码，不是登录密码
- ✅ **OAuth 2.0** - OneDrive使用标准OAuth授权
- ✅ **权限最小化** - 仅请求必要的文件访问权限

### 隐私保护
- ✅ **完全本地化** - 不经过任何第三方服务器
- ✅ **用户完全控制** - 数据存储位置和时机完全由用户决定
- ✅ **可选功能** - 不使用云存储不影响核心功能
- ✅ **开源透明** - 所有代码开源，可审计

## 📊 技术特点

### 架构设计
```
UI层 (CloudStorageSettings)
    ↓
管理层 (CloudStorageManager)
    ↓
客户端层 (WebDAVClient / OneDriveClient)
    ↓
网络层 (Fetch API / Graph API)
```

### 核心技术
- 🎯 **统一接口** - 所有云服务使用统一的API
- 🔔 **事件驱动** - 基于EventEmitter的状态管理
- 🔄 **自动重试** - 网络错误自动重试机制
- ⏰ **定时同步** - 可配置的自动同步调度
- 🛡️ **错误处理** - 完善的错误捕获和提示

### 性能优化
- ⚡ 单例模式减少实例创建
- ⚡ 事件驱动减少轮询开销
- ⚡ 智能调度避免频繁同步
- ⚡ 本地缓存减少网络请求

## 🔧 配置示例

### 坚果云配置
```typescript
{
  provider: 'webdav',
  webdav: {
    url: 'https://dav.jianguoyun.com/dav/',
    username: 'your@email.com',
    password: 'app-password-here',
    remotePath: '/PromptMate'
  },
  autoSync: true,
  syncInterval: 30
}
```

## ❓ 常见问题

### Q: 支持哪些云存储服务？
A: 目前支持所有WebDAV协议的服务（坚果云、ownCloud、NextCloud等）和OneDrive。未来计划支持Google Drive、Dropbox等。

### Q: 数据会经过第三方服务器吗？
A: 不会！数据直接从您的设备传输到您选择的云存储服务，完全不经过任何第三方服务器。

### Q: 免费用户可以使用吗？
A: 当然可以！但请注意：
- 坚果云免费版：1GB/月上传，3GB/月下载
- OneDrive免费版：5GB总容量

### Q: 同步会覆盖我的数据吗？
A: 
- "上传"：会覆盖云端数据
- "下载"：会覆盖本地数据  
- "同步"：智能合并（以本地为主）

### Q: 可以同时配置多个云存储吗？
A: 当前版本一次只能使用一个云存储服务。未来版本可能支持多云同步。
