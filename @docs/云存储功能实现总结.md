# PromptMate 云存储功能实现总结

## 📋 项目概述

本次更新为 PromptMate 添加了完整的云端存储功能，支持 WebDAV（坚果云等）和 OneDrive 云存储服务。该功能参考了 CherryStudio 项目的实现方式，为用户提供了安全、可靠的数据跨设备同步方案。

## ✨ 核心功能

### 1. 多云存储支持
- **WebDAV**：支持坚果云、ownCloud、NextCloud 等所有 WebDAV 协议的服务
- **OneDrive**：微软官方云存储服务
- **可扩展**：架构设计支持未来添加更多云服务（Google Drive、Dropbox 等）

### 2. 灵活的同步策略
- **自动同步**：可配置定时自动同步（5-1440 分钟）
- **手动同步**：随时手动触发数据同步
- **独立操作**：支持单独上传或下载操作
- **状态监控**：实时显示同步状态、时间和错误信息

### 3. 完善的用户体验
- **连接测试**：保存前可测试配置是否正确
- **预设配置**：提供常用服务的预设配置（如坚果云）
- **错误提示**：详细的错误信息和解决建议
- **状态徽章**：直观的同步状态显示

### 核心组件

#### 1. WebDAVClient (`src/services/cloudStorage/WebDAVClient.ts`)

**功能：**
- 完整的 WebDAV 协议实现
- 支持文件上传、下载、列表、删除
- 自动创建目录
- 连接测试和错误处理

**特点：**
- 使用 Fetch API 实现，无需额外依赖
- Basic 认证支持
- XML 解析支持
- 预定义服务商配置

**代码示例：**
```typescript
const client = new WebDAVClient({
  url: 'https://dav.jianguoyun.com/dav/',
  username: 'your@email.com',
  password: 'app-password',
  remotePath: '/PromptMate'
});

// 上传文件
await client.uploadFile('data.json', content);

// 下载文件
const content = await client.downloadFile('data.json');

// 测试连接
const connected = await client.testConnection();
```

#### 2. OneDriveClient (`src/services/cloudStorage/OneDriveClient.ts`)

**功能：**
- Microsoft Graph API 集成
- OAuth 2.0 授权流程
- 自动令牌刷新
- 完整的文件和目录操作

**特点：**
- 标准的 OAuth 2.0 实现
- 令牌过期检测
- 错误重试机制
- Graph API v1.0

**代码示例：**
```typescript
const client = new OneDriveClient({
  clientId: 'your-client-id',
  accessToken: 'access-token',
  refreshToken: 'refresh-token',
  remotePath: '/PromptMate',
  expiresAt: '2025-10-19T00:00:00Z'
});

// 上传文件
await client.uploadFile('data.json', content);

// 下载文件
const content = await client.downloadFile('data.json');
```

#### 3. CloudStorageManager (`src/services/cloudStorage/CloudStorageManager.ts`)

**功能：**
- 统一的云存储接口
- 客户端生命周期管理
- 自动同步调度
- 事件驱动的状态通知

**特点：**
- 单例模式
- EventEmitter 事件系统
- 自动重连机制
- 状态持久化

**事件系统：**
```typescript
cloudStorageManager.on('initialized', (info) => {
  console.log('云存储已初始化:', info);
});

cloudStorageManager.on('syncStart', () => {
  console.log('开始同步...');
});

cloudStorageManager.on('syncComplete', (status) => {
  console.log('同步完成:', status);
});

cloudStorageManager.on('syncError', (error) => {
  console.error('同步失败:', error);
});
```

## 🔧 类型定义

### CloudStorageSettings
```typescript
interface CloudStorageSettings {
  enabled: boolean;                  // 是否启用
  provider: CloudStorageProvider;    // 服务商
  autoSync: boolean;                 // 自动同步
  syncInterval: number;              // 同步间隔（分钟）
  lastSyncTime?: string;            // 最后同步时间
  webdav?: WebDAVConfig;            // WebDAV 配置
  onedrive?: OneDriveConfig;        // OneDrive 配置
}
```

### WebDAVConfig
```typescript
interface WebDAVConfig {
  url: string;                       // 服务器地址
  username: string;                  // 用户名
  password: string;                  // 密码/应用密码
  remotePath: string;                // 远程路径
}
```

### OneDriveConfig
```typescript
interface OneDriveConfig {
  clientId: string;                  // 客户端 ID
  accessToken?: string;              // 访问令牌
  refreshToken?: string;             // 刷新令牌
  remotePath: string;                // 远程路径
  expiresAt?: string;               // 过期时间
}
```

### CloudSyncStatus
```typescript
interface CloudSyncStatus {
  syncing: boolean;                  // 是否正在同步
  lastSync?: string;                // 最后同步时间
  lastError?: string;               // 最后错误
  filesCount?: number;              // 文件数量
}
```

## 🎯 使用场景

### 场景 1：多设备同步
用户在办公室电脑上创建了一些提示词，回家后想在家里的电脑上继续使用。

**解决方案：**
1. 在办公室电脑上配置云存储（如坚果云）
2. 启用自动同步
3. 在家里的电脑上配置相同的云存储
4. 数据自动同步，无缝切换

### 场景 2：数据备份
用户担心本地数据丢失，想要有云端备份。

**解决方案：**
1. 配置云存储服务
2. 定期手动上传或启用自动同步
3. 数据自动备份到云端
4. 需要时可随时下载恢复

### 场景 3：团队协作
团队成员需要共享提示词库。

**解决方案：**
1. 使用团队坚果云账号或 OneDrive 企业版
2. 配置相同的远程路径
3. 团队成员都可以同步到最新数据
4. 实现知识库共享
